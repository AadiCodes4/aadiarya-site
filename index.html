Projects

Things I've built

QuantAlpha

Python · scikit-learn · pytest · Docker

An algorithmic-trading simulation engine. Models multi-exchange market microstructure end to end, detects cross-exchange arbitrage opportunities filtered by fee and slippage thresholds, and trains a GradientBoostingClassifier and Ridge regressor on lagged-return features to predict price direction and magnitude, backed by a full pytest suite and Docker packaging.

NeuroScribe

Python · PyTorch · FastAPI · React · Docker

A synthetic medical-imaging segmentation pipeline. Generates procedural scan data, trains a U-Net (SmallUNet) with combined BCE and Dice loss, and serves predictions with gradient-based interpretability (saliency and Grad-CAM-style heatmaps) through a FastAPI backend. Built as an educational, non-clinical prototype.
